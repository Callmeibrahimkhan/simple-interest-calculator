
# Simple Interest Calculator

## Project Description
This project is a simple interest calculator developed using Bash scripting.

It calculates simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal Amount
- Rate of Interest
- Time Period
